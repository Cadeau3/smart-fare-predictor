# Smart Fare Predictor – Kenya Transport Cost Estimator

The **Smart Fare Predictor** is an interactive, browser-based tool that estimates typical bus, matatu, and boda fares across Kenyan towns. It uses distance calculations, fuel price modeling, time-of-day effects, weather conditions, and service-type multipliers to generate clear and realistic fare predictions. The tool is fully client-side, requires no installation, and is designed in a soft pastel transport theme for a clean, friendly user experience.

### 🔗 Live Demo  
https://cadeau3.github.io/smart-fare-predictor/

---

## 🌍 Project Purpose

Public transport costs in Kenya change frequently depending on fuel prices, peak hours, weather, distance, and type of service. This project explores how **simple data modeling and computer science** can help users understand these fluctuations. I built this tool to demonstrate how technology can interpret real-world factors and present them in a way that is accessible and meaningful to everyday commuters.

The model is heuristic—not an official tariff calculator—but it shows how computational thinking can be applied to real community challenges.

---

## ✨ Features

- Distance estimation using Haversine formula  
- Adjustable fuel price slider + sensitivity chart  
- Time-of-day multipliers (peak, off-peak, night)  
- Weather effect (rain surcharge)  
- Vehicle options: matatu, bus, boda  
- Regular and express service types  
- Automated fare breakdown explanation  
- Export fare results to CSV  
- Fully client-side, no backend required  

---

## 🧠 How the Fare Model Works

The predictor uses:  
- Base per-km rates for each vehicle  
- Fuel efficiency assumptions  
- A dynamic fuel multiplier (cost-per-km impact)  
- Behavior-based modifiers (peak hours, rain, express service)  
- A final combined formula to estimate fare  

This structure keeps the model **transparent and interpretable**.
