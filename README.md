# Smart Fare Predictor – Kenya Transport Cost Model

The **Smart Fare Predictor** is an interactive, browser-based tool that estimates typical transport fares for matatus, buses, and bodas across major Kenyan towns. It models how distance, fuel prices, peak hours, weather conditions, and service type influence the expected fare. This project is fully client-side, requires no installation, and features a soft pastel interface designed for clarity and accessibility.

### 🔗 Live Demo  
https://cadeau3.github.io/smart-fare-predictor/

---

## 🌍 Project Purpose

Transport costs in Kenya change frequently due to factors like fuel prices, time of day, congestion, distance, and weather. I created this project to explore how **simple computational modeling** can help commuters understand these shifts through a transparent and easy-to-use interface. The tool does not attempt to predict official fares, but instead demonstrates how data and everyday observations can be converted into a useful, interpretable model.

This project highlights my interest in using computer science to address real-world challenges affecting local communities.

---

## ✨ Features

- Calculates fare using distance + multipliers (fuel, time, weather, service type)  
- Uses Haversine formula for accurate distance estimation  
- Fuel-price sensitivity chart (interactive)  
- Fare breakdown showing how each factor influences the result  
- Export predicted fare as CSV  
- Pastel UI theme for a simple, friendly experience  
- Fully runs in the browser (no backend required)

---

## 🧠 How the Fare Model Works

The model uses:  
- Base per-km rates for matatu, bus, and boda  
- Fuel efficiency assumptions  
- A proportional fuel-price multiplier  
- Time-of-day surcharges (peak, night)  
- Rain surcharge  
- Express vs. regular service adjustments  

This makes the estimator **transparent, explainable, and easy to understand**.
